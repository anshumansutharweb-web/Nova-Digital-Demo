# Nova Digital — Responsive Business Website

A portfolio demo project built with HTML, CSS, and vanilla JavaScript.

## Run locally
1. Open this folder in Visual Studio Code.
2. Open `index.html` in a browser, or use the VS Code Live Server extension if you have it.
3. Before publishing, replace `hello@example.com` in `index.html` and `script.js` with your own project email.

## Files
- `index.html` — semantic page structure and content
- `style.css` — responsive styles and layout
- `script.js` — mobile navigation, current year, and demo email form

## Important
The contact form opens the visitor's email application using a `mailto:` link. It does not save form submissions on a server. For a real client website, connect a form provider or backend and test spam protection.

## Free deployment using GitHub Pages
1. Create a GitHub repository named `nova-digital` (or another name).
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. In the repository, open Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the `main` branch and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish and open the URL shown in Settings → Pages.

This is a demo concept. Replace the brand, contact details, project examples, and copy before presenting it as a client's website.
